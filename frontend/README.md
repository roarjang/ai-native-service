# AI Native Chat 화면

Day03 React + TypeScript 화면입니다. 대화 목록, 생성·삭제, 메시지 조회와 AI 답변 스트리밍을 제공합니다. 브라우저 요청에는 `X-Client-Id: student-web` 헤더를 보냅니다.

## 개발 실행

백엔드를 `http://127.0.0.1:8000`에서 실행한 뒤:

```bash
cd frontend
npm ci
npm run dev
```

Vite 개발 서버는 `/api` 요청을 백엔드로 프록시합니다. 브라우저에서는 개발 서버가 출력한 주소를 엽니다. 별도의 `VITE_API_BASE_URL` 설정은 필요하지 않습니다.

## 빌드

```bash
npm run build
```

빌드 결과는 `frontend/dist/`에 생성됩니다. 백엔드는 이 폴더가 있으면 `/`에서 화면을 제공하며 API 경로는 그대로 유지합니다. `dist/`와 `node_modules/`는 Git에 포함하지 않습니다.

## 응답 실패 시

스트림 연결이 성립한 뒤 AI 응답에 실패하면 서버에는 사용자 질문과 실패한 AI 실행 이력이 남습니다. 화면은 메시지 목록을 다시 읽고, 입력창을 비워 같은 질문의 무심코 재전송을 막습니다. 연결 자체가 실패하면 입력을 유지하므로 대화 기록을 확인한 뒤 재시도할 수 있습니다.
